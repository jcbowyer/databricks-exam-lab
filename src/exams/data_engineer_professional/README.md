# data_engineer_professional

Databricks Certified Data Engineer Professional. Each subfolder is one official exam section, with its own README.
The `data_engineer_professional` job runs every notebook in folder order.
The declarative pipeline in `03_data_transformation_cleansing_and_quality` runs as a `pipeline_task` that points at `resources/pipelines.yml`.
