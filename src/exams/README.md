# exams

One folder per certification. Each subfolder inside is one official exam section, named after the section title and headed by its weight.

| Folder | Certification | Job |
|---|---|---|
| `spark_developer_associate/` | Databricks Certified Associate Developer for Apache Spark | `spark_developer_associate` |
| `data_engineer_professional/` | Databricks Certified Data Engineer Professional | `data_engineer_professional` |

The live-coding patterns that both exams assume live separately in `src/interview_drills/` (not an exam section).
