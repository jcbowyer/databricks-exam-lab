# spark_developer_associate

Databricks Certified Associate Developer for Apache Spark. Each subfolder is one official exam section, with its own README.
The `spark_developer_associate` job runs every notebook in folder order.

| Folder | Exam section | Weight |
|---|---|---|
| `01_apache_spark_architecture_and_components` | Apache Spark Architecture and Components | 20% |
| `02_using_spark_sql` | Using Spark SQL | 20% |
| `03_developing_dataframe_dataset_api_applications` | Developing Apache Spark™ DataFrame/DataSet API Applications | 30% |
| `04_troubleshooting_and_tuning_dataframe_api_applications` | Troubleshooting and Tuning Apache Spark DataFrame API Applications | 10% |
| `05_structured_streaming` | Structured Streaming | 10% |
| `06_using_spark_connect_to_deploy_applications` | Using Spark Connect to deploy applications | 5% |
| `07_using_pandas_api_on_apache_spark` | Using Pandas API on Apache Spark | 5% |
